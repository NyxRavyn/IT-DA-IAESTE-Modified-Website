IAESTE LC JECRC — Department SVG icons

Copy all eight SVG files into your website's images/ folder.

Suggested mapping:
- Incoming Exchange  -> incoming-exchange.svg
- Outgoing Exchange  -> outgoing-exchange.svg
- Corporate Relations -> corporate-relations.svg
- Marketing -> marketing.svg
- Design & Media -> design-media.svg
- IT-DA -> it-data.svg
- Events & Culture -> events-culture.svg
- Human Resources -> human-resources.svg

Use them in departments.html like:
<img class="department-icon" src="images/incoming-exchange.svg" alt="" aria-hidden="true">

Suggested CSS:
.department-icon {
  width: 56px;
  height: 56px;
  object-fit: contain;
  display: block;
  margin-bottom: 14px;
}

All icons use the existing navy (#14305c), blue (#2f5d9b), and gold (#f2b84b)
palette, with rounded strokes to match the four illustrations in the
'More than an internship' section.
